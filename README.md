Leonida Legend — an offline guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI: a guide in its own words for every trophy with its sources cited, a roadmap to the platinum, missable trophies flagged, and a checklist saved in the browser with export/import, filters, and a spoiler setting that hides story trophies until they are earned.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. The guide is plain static files under app/ and works with the network off.
